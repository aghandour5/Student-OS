## 2024-05-18 - Replacing O(N) Array Lookups with O(1) Sets in React Context
**Learning:** In highly trafficked React Contexts (like `AcademicContext`), mapping operations or frequent updates can trigger widespread component re-renders. A major performance bottleneck occurs when derived status computations inside mapping functions repeatedly use `array.includes()` on potentially large user progress arrays (`completedCourses`, `inProgressCourses`). This creates an O(N^2) or worse time complexity for overall page renders because every component queries the arrays inside the context functions.
**Action:** Use `useMemo` to precompute `Set` versions of these status arrays (`completedSet`, `inProgressSet`) directly inside the Context provider component. Update all read-heavy Context callback functions to perform O(1) `Set.has()` checks instead of O(N) `Array.includes()` checks. Ensure that functional state updaters (`setProfile(prev => ...)`) continue to evaluate the current `prev` state rather than the memoized derived state.
