## 2024-05-24 - Optimizing BFS graph traversals in React
**Learning:** Prerequisite calculations (`getPrerequisiteChain`) involve BFS graph traversals. The algorithm must use both a global `visited` Set to track processed nodes across the tree and a local `nextLevelSet` to prevent duplicate processing within the exact same breadth level in diamond dependency structures (e.g., A->B->D and A->C->D). Additionally, pre-computing reference arrays (e.g., `completedCourses`) into a `Set` prior to the loop execution converts O(N) array `.includes()` operations into O(1) Set `.has()` lookups, avoiding heavy performance bottlenecks during iterative graph traversals.
**Action:** When implementing graph traversals or iterative data aggregations over relationships, always pre-compute search arrays into Sets. Furthermore, ensure BFS iterations use local cycle-prevention Sets to handle diamond-shaped dependencies optimally.
