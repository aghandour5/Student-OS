## 2025-04-11 - Optimizing Prerequisite Array Includes with Memoized Sets
**Learning:** Checking prerequisites (`completedCourses.includes(pid)`) using `Array.includes` inside iterative mapping/filtering methods results in O(n^2) operations. In applications managing many courses and checking states frequently during renders (e.g. `getCourseStatus`, `arePrereqsMet`), this presents a significant bottleneck. Furthermore, prerequisite chains with diamond structures (A->B->D and A->C->D) can lead to redundant operations within the same level when calculating graph paths (`getPrerequisiteChain`), since a standard `visited` set only blocks traversals in future levels.
**Action:** Extract memoized `Set` instances for arrays like `completedCourses` and `inProgressCourses` derived from `profile.progress` using `useMemo`. Update `useCallback` read-only operations to use `Set.has(pid)` (O(1)) instead of `Array.includes(pid)`. For BFS graph algorithms, include a local level `Set` (`nextLevelSet`) to deduplicate nodes being concurrently queued in the exact same level.
