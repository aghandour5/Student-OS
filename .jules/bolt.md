## 2025-02-24 - O(N) Array lookups in Contexts causing excessive rendering costs
**Learning:** In `lib/academic-context.tsx`, many React components subscribed to the context were evaluating O(N) array `.includes()` operations inside critical functions like `arePrereqsMet` and `getCourseStatus`. This caused significant CPU load because React contexts pass functions down that are frequently re-evaluated during render cycles, creating O(N * M) complexities when iterating over arrays in child components.
**Action:** Extract and memoize Sets (`completedCoursesSet`, `inProgressCoursesSet`) directly from the profile state early in the context provider. Substitute all array `.includes()` checks inside `useCallback` hooks with Set `.has()` checks for fast O(1) lookups, preventing excessive render time. Use separate Set tracking (like `nextLevelSet`) to prevent duplicate processing within breadth levels in BFS graph traversal.
