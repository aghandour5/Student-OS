## 2025-04-17 - React Context Derived Set Memoization and Graph BFS Level Set Optimization
**Learning:** We observed O(N) array `.includes()` operations being unnecessarily re-evaluated whenever unrelated user profile state (like `notes`) changed, triggering expensive cascading re-renders in consumer lists. Passing full `profile` objects to `useCallback` hook dependency arrays was the root cause. Furthermore, `getPrerequisiteChain` performed duplicate BFS explorations across branches of the same depth due to missing diamond dependency deduplication.
**Action:** Extract and convert arrays (like `completedCourses`) into Sets using `useMemo` specifically on those sliced properties, avoiding exhaustive-deps issues. Feed only the Sets into the dependency array of handlers (`arePrereqsMet`, `getCourseStatus`, `getPrerequisiteChain`) so they update O(1) checks without unnecessary recreation. In graph BFS algorithms on identical levels, employ a `nextLevelSet` to preclude sibling branches queuing the exact same node concurrently.
