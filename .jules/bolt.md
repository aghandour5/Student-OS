## 2024-05-18 - Replacing Array .includes() with Set .has() in Hot Paths
**Learning:** Checking prerequisites and course statuses relies heavily on evaluating if an item exists within large arrays (completedCourses and inProgressCourses) via O(N) operations. Because these callbacks (`arePrereqsMet`, `getCourseStatus`, `isYearCompleted`, etc.) are deeply integrated into React component trees and called repeatedly during bulk list rendering, the nested looping results in O(N^2) bottlenecks rendering lists slow.
**Action:** Always derive `Set` structures from raw Array state immediately in the React context or component scope using `useMemo`, and replace `.includes()` lookups with `.has()` lookups in the corresponding callbacks to improve time complexity to O(1) in the hot render paths.
