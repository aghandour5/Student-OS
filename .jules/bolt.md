## 2025-02-19 - Fix Diamond Dependency Duplicate Bug and optimize lookups
**Learning:** In the academic prerequisite algorithm `getPrerequisiteChain`, BFS graph traversals had a specific edge case where diamond dependency structures (e.g. A->B->D and A->C->D) caused duplicate processings in the same breadth level. The global `visited` Set was not sufficient for preventing this. Additionally, O(N) array '.includes()' checks on derived Sets within inner callbacks were causing O(N*M) bottlenecks during context evaluations.
**Action:** Always maintain a local `nextLevelSet` inside BFS loops to track queued nodes for the next level. Move derived React State like Sets outside of React Hook internal derivations to correctly satisfy exhaustive-deps and ensure O(1) rendering lookups.
