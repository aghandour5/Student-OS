## 2025-04-25 - Optimize Array Lookups in Academic Logic
**Learning:** In `lib/academic-context.tsx`, checking if a course is completed or in progress using O(N) `array.includes()` inside loops and `.every()`/`.filter()` calls leads to an O(N*M) bottleneck, significantly degrading rendering performance when processing many courses in UI lists. Furthermore, extracting array-derived Sets directly within a `useMemo` dependency array using optional chaining (e.g., `profile?.courses`) violates exhaustive-deps lint rules.
**Action:** Extract the optional array chain into a separate variable *before* the `useMemo` block, and derive `Set` objects for O(1) `.has()` lookups in read-only calculations (`getCourseStatus`, `arePrereqsMet`). Keep using `prev...includes()` inside `setProfile` updaters to ensure evaluation against the most recent state and avoid stale closures.
