## 2024-06-25 - Context State Extraction for O(1) Lookups & BFS Deduplication
**Learning:** React Context functions that operate on deep object properties (like `profile.progress[profile.major].completedCourses`) and use `.includes()` introduce O(N) penalties during renders. Furthermore, the BFS algorithm in `getPrerequisiteChain` can enqueue the same dependency multiple times at the same depth in diamond structures.
**Action:** Extract deep array state (e.g. `completedCourses`) into a top-level memoized `Set` prior to hook declarations. Pass these Sets as dependencies and use `.has()` to achieve O(1) lookups, decoupling handlers from unrelated state changes. In BFS traversals, use both a global `visited` Set and a local `nextLevelSet` to deduplicate queue additions within the same level.
