## 2024-05-19 - O(1) Lookups for Academic Context
**Learning:** Evaluated loops in `lib/academic-context.tsx` (`arePrereqsMet`, `getCourseStatus`, `getMissingPrereqs`, `getPrerequisiteChain`) previously used `Array.includes()` on `currentProgress.completedCourses` and `inProgressCourses`. Given that some of these functions are called frequently (e.g. `getCourseStatus` inside mapping operations) and involve traversing arrays, it's a measurable performance anti-pattern.
**Action:** Implemented `completedSet` and `inProgressSet` using `useMemo` right below the profile update logic, converting O(N) lookup operations to O(1) Set operations. Extracted optional chaining on `profile.progress[profile.major]` into a separate variable before `useMemo` to ensure ESLint dependency matching avoids infinite loops/missing triggers. Replaced `includes()` with `.has()`.
