## 2024-05-20 - [O(1) Set Lookups for Context Callbacks]
**Learning:** Callbacks in React Contexts (like `getCourseStatus` or `arePrereqsMet`) often process lists and arrays. Relying on deep context dependencies (like the full `profile` object) to run O(N) array inclusion checks causes unnecessary recreation of callbacks and subsequent expensive cascading re-renders across the app. Moreover, BFS traversals using basic graph patterns can fall into duplicate processing traps in diamond dependency structures without specific `nextLevel` deduping.
**Action:** Always extract O(1) Data Structures (like `Set`) directly from specific nested object state *before* `useMemo` hooks, and explicitly limit dependency arrays for context methods to these derived Sets instead of the full root state object. Also use Sets to prevent inserting duplicates into BFS chain levels.
