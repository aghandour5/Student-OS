## 2024-06-25 - Optimize BFS graph traversal for course prerequisite chains
**Learning:** In applications utilizing BFS for prerequisite or dependency tree generation, failing to convert large datasets (e.g., arrays of `completedCourses`) into a `Set` before loops introduces massive O(N) penalties at each node. Furthermore, diamond dependency graphs can push identical node objects into the same BFS level array, compounding traversal costs and inflating memory usage if a local level-scoped `Set` deduplication is not in place.
**Action:** When implementing any tree or graph traversal logic (BFS/DFS), always pre-compute search arrays (like missing prerequisites) into Sets for O(1) checks. Always incorporate a local `nextLevelSet` to deduplicate queue insertions in single breadth levels alongside the standard global `visited` set to prevent double-processing in diamond structures.
