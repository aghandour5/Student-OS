## 2024-06-21 - Optimize React Context O(N) Array Checks to O(1) Sets
**Learning:** In complex Context providers (`AcademicProvider`), functions calculating derived state (like BFS traversals in `getPrerequisiteChain` or filter methods in `getMissingPrereqs`) often repeatedly scan large arrays like `completedCourses` using `Array.includes()`. When these functions are evaluated during renders or loops, the O(N) array scans create hidden N*M or N^2 performance bottlenecks.
**Action:** Extract large arrays into `useMemo` Sets (e.g., `completedSet`, `inProgressSet`) and use `Set.has()` for O(1) lookups in read-only Context methods. Remember: Never use these derived Sets inside functional state updaters (`setProfile(prev => ...)`) to avoid stale closure state; always read from `prev` directly inside updaters.
