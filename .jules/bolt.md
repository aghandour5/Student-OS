## 2024-05-18 - Optimize academic context performance (O(1) lookups & BFS deduplication)
**Learning:** During prerequisite graph traversals (BFS) and frequent course status recalculations within `lib/academic-context.tsx`, relying on `Array.includes()` for checking `completedCourses` and `inProgressCourses` can lead to repeated O(N) evaluations. Converting these arrays to Sets (`completedCoursesSet` and `inProgressCoursesSet`) significantly optimizes lookup times to O(1). Additionally, using a `nextLevelSet` during BFS traversals successfully deduplicates redundant processing within the exact same breadth level, which is a key performance improvement for complex, diamond-pattern prerequisite chains.
**Action:** When implementing algorithms that involve frequent list lookups or breadth-first search traversals on React context state, proactively memoize those lists into O(1) Sets using `useMemo` and use dedicated Sets to track nodes to deduplicate processing at the same algorithm stage.
