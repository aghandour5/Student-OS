## 2025-03-29 - [Optimize Graph BFS & React Context Sets]
**Learning:** In complex graph traversal (like BFS for academic prerequisites), diamond dependencies (A->B->D, A->C->D) can cause identical nodes to be repeatedly queued in the same breadth level if only a global `visited` set is used after pulling from the queue. Additionally, heavily reliant `Array.includes()` across derived context state scales linearly O(N^2) relative to list size.
**Action:** When implementing BFS layers, maintain a local `nextLevelSet` to validate additions to the queue for that exact depth level. Furthermore, always intercept array context state directly out of a `useMemo` dependency array, convert it to a `Set<string>`, and use O(1) `.has()` checks for operations repeatedly invoked during renders.
